Concept Proposal / 创新产品概念方案未开发上线

AI + AUTOMOTIVE · MULTI-AGENT

DriveMate

面向城市通勤、家庭出行和长途驾驶用户的多Agent智能出行与车况助手。

痛点01

行程信息分散

地图、天气、日程与同行人安排彼此割裂。

痛点02

车况难以理解

电量、胎压和维保状态缺少面向普通用户的解释。

痛点03

补能无法统筹

路线、充电站、停留时间和到达目标需要联合规划。

痛点04

助手缺少连续执行

传统语音交互难以拆解并完成跨工具复合任务。

产品方案与Agent协作

ORCHESTRATORDriveMate 主Agent

拆解任务、协调专业Agent、选择工具、汇总事实和推断，并在关键动作前请求确认。

出行规划Agent地图 / 交通 / 天气
车辆状态解释Agent电量 / 胎压 / 维保状态
补能规划Agent续航 / 充电站 / 停留时间
日程与提醒Agent日程 / 出发提醒 / 到达目标
应急支持Agent异常解释 / 道路救援 / 专业服务

工具调用范围

地图和交通路线、拥堵、预计用时
天气降雨、温度、预警
用户日程时间约束、提醒
车辆状态电量、胎压、维保
充电站位置、可用性、功率

典型任务：“明天上午带家人从上海去苏州，帮我检查车辆状态、规划补能并结合日程安排出发时间。”

USER JOURNEY

从一句复合需求到可确认计划

01理解任务

识别目的地、同行人、时间和补能要求。

02读取事实

日程、天气、交通、车辆与充电站数据。

03协同规划

各Agent生成路线、出发窗口和补能候选。

04风险确认

标注异常、来源、假设与需用户确认的动作。

05输出计划

形成出发时间、路线、补能、提醒和应急建议。

SAFETY BOUNDARY

安全边界

  • 不直接执行高风险车辆控制；
  • 关键操作需用户确认；
  • 区分车辆事实数据与模型推断；
  • 车辆异常优先建议联系专业服务；
  • 工具数据缺失或冲突时明确提示，不补造事实。

EVALUATION

评测指标

任务完成率工具调用准确率信息事实性 用户确认次数响应时间用户满意度高风险错误率
